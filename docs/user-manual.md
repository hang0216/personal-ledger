## 1. 系统简介

个人记账本是一款单用户 Web 应用，提供三大基础模块与三项增强功能：

| 模块 | 入口 | 能力 |
| --- | --- | --- |
| 数据看板 | `/` | 月度收入/支出/结余、支出分类占比饼图、月度预算与超支提醒 |
| 账单管理 | `/transactions` | 账单新增/编辑/删除、月份与类型筛选、搜索、CSV 导出 |
| 分类管理 | `/categories` | 查看预置分类、新增分类、删除分类 |

数据保存在服务器本地 SQLite 文件（默认 `backend/ledger.db`），无需外部数据库。

## 2. 本地启动

### 2.1 环境要求

- Python 3.11+
- Node.js 18+（仅前端开发/构建需要）
- 浏览器：Chrome / Edge / Firefox 最新版

### 2.2 启动后端

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

访问 `http://127.0.0.1:8000/api/health`，返回 `status: ok` 即正常。
开发模式可访问接口文档 `http://127.0.0.1:8000/docs`。

首次启动会自动建表并写入 13 条预置分类。

### 2.3 启动前端（开发模式）

```bash
cd frontend
npm install
npm run dev
```

访问 `http://localhost:5173`。前端通过 CORS 直连 `http://127.0.0.1:8000`。

### 2.4 生产构建

```bash
cd frontend
npm run build
```

构建产物 `frontend/dist/` 存在时，后端会自动同源托管页面，直接访问 `http://127.0.0.1:8000` 即可。

## 3. 数据看板（首页 `/`）

1. 页面顶部为预算条：
   - 未设置：「本月预算 未设置」+「设置预算」按钮
   - 已设置：预算金额、已支出金额、使用率进度条；超支时显示「已超支 ¥N」
2. 点击「设置预算」/「修改预算」→ 输入金额（元，最多 2 位小数）→ 保存。
3. 若本月支出超过预算，进入页面会弹出「预算超支提醒」，同一月份只弹一次。
4. 中部为三张统计卡片：本月收入、本月支出、结余（负数显示 `-¥`）。
5. 下方为支出分类占比饼图与明细列表；无数据时显示空状态。
6. 右上角月份切换：`◀` / `▶` 或日期选择器，只能选择当前月及更早月份。

> 预算只影响提示，不会阻止记账。

## 4. 账单管理（`/transactions`）

### 4.1 查看与筛选

- 顶部月份选择切换账期；账单按日期倒序、同日按 id 倒序。
- 类型下拉：全部 / 收入 / 支出；分类下拉随类型联动。
- 点击「重置」清空类型与分类筛选并回到当前月。

### 4.2 新增账单

1. 点击「新增账单」。
2. 填写：类型、金额、分类、日期、备注（可选，≤100 字）。
3. 保存后列表刷新，出现成功提示。

校验规则：

- 金额 > 0、最多 2 位小数、≤ 99,999,999.99
- 日期格式 `YYYY-MM-DD`，不早于 2000-01-01，不晚于今天
- 分类必须存在且与类型一致

### 4.3 编辑 / 删除

- 行内「编辑」打开弹窗，字段自动回填；保存为全量更新。
- 行内「删除」弹出二次确认；确认后删除，取消不改变数据。

### 4.4 搜索

第二行搜索区支持：

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 可只填开始或结束；跨月查询 |
| 备注关键词 | 模糊匹配，≤100 字，首尾空格自动忽略 |
| 类型 / 分类 | 可同时叠加 |

操作：

1. 填写条件 → 点击「查询」或关键词框回车。
2. 出现「当前为搜索模式…月份选择不生效」提示，列表为筛选结果。
3. 点击「清除搜索」恢复当前月份视图。

注意：

- 开始日期不能晚于结束日期。
- 关键词中的 `%`、`_` 按普通字符匹配。

### 4.5 导出 CSV

1. 先筛选出需要的账单（月份视图或搜索结果）。
2. 点击「导出 CSV」，浏览器下载 `账单_YYYY-MM-DD.csv`。
3. 用 Excel 双击打开即可，列：日期、类型、分类、金额(元)、备注。

说明：导出内容就是当前列表；列表为空时按钮不可用。

## 5. 分类管理（`/categories`）

- 页面按「支出分类」「收入分类」分组展示与计数。
- 点击「新增分类」：填写名称（1–20 字，自动去首尾空格）并选择类型。
- 同名同类型不允许（提示「该分类已存在」）。
- 删除分类前会二次确认；若该分类下已有账单，会提示「该分类下存在记录，无法删除」。
- 分类不支持重命名或修改类型。

## 6. 错误提示对照

| 错误码 | 提示文案 | 常见原因 | 处理 |
| --- | --- | --- | --- |
| 1001 | 参数不合法 / 备注长度超限 / 分类名称不合法 / 关键词长度超限 | 输入为空、超长 | 按字段提示修改 |
| 1002 | 金额不合法 | 空、非数字、≤0、超 2 位小数 | 输入正数，最多 2 位小数 |
| 1003 | 金额超出允许范围 | 超过 99,999,999.99 | 降低金额 |
| 1004 | 日期不合法 / 日期范围不合法 | 格式错误、超出范围、开始晚于结束 | 重新选择日期 |
| 1005 | 月份不合法 | 月份格式错误 | 使用月份控件选择 |
| 1006 | 分类类型与收支类型不一致 | 选了收入类型却用支出分类 | 重新选择分类 |
| 1007 | 分类不存在 | 分类已被删除 | 刷新后重新选择 |
| 1008 | 记录不存在 | 账单已被删除 | 刷新列表 |
| 1009 | 该分类已存在 | 同类型重名 | 换一个名称 |
| 1010 | 该分类下存在记录，无法删除 | 分类被账单引用 | 先处理相关账单 |
| 1999 | 服务器内部错误 | 服务异常 | 稍后重试，查看后端日志 |

网络异常：页面顶部提示请求失败，检查后端是否启动、网络是否可用。

## 7. 数据备份与恢复

**备份（推荐停服务后执行）**

```bash
# Windows
copy backend\ledger.db backend\ledger.db.bak-20261021

# macOS / Linux
cp backend/ledger.db backend/ledger.db.bak-$(date +%Y%m%d)
```

**恢复**

```bash
copy backend\ledger.db.bak-20261021 backend\ledger.db
cp backend/ledger.db.bak-20261021 backend/ledger.db
```

**数据库位置**

- 本地默认：`backend/ledger.db`
- 可用环境变量 `LEDGER_DB_PATH` 指定其他路径
- 云端脚本默认：`$HOME/personal-ledger-data/ledger.db`（代码目录之外，重新部署不覆盖）

## 8. 云端部署（CloudStudio）

1. 上传部署包 `personal-ledger-cloudstudio.zip` 到 `/workspace`。
2. 解压：`python3 -m zipfile -e personal-ledger-cloudstudio.zip personal-ledger`。
3. 启动：`cd personal-ledger && bash deploy/cloudstudio-start.sh`。
4. 脚本行为：
   - 设置 `LEDGER_ENV=production`（关闭 `/docs`）
   - 设置数据库路径 `$HOME/personal-ledger-data/ledger.db`
   - 安装后端依赖；`frontend/dist` 已随包提供，无需再次构建
   - 以 `0.0.0.0:8000` 启动
5. 升级：备份代码与数据库 → 停止服务 → 覆盖解压 → 重新启动。
6. 回滚：恢复备份目录与数据库文件后重启。

安全提醒：当前版本没有登录鉴权，同一链接的所有访问者共享一份数据；正式使用请将端口权限设为仅自己可见。

## 9. 常见问题（FAQ）

| 问题 | 处理 |
| --- | --- |
| 页面空白 / 接口 502 | 确认后端已启动、端口 8000 监听正常 |
| 前端提示跨域错误 | 开发模式确认后端 CORS 含 `http://localhost:5173`；生产请用同源访问 |
| 预算一直显示「未设置」 | 确认选择的月份与设置月份一致；检查 `budgets` 表是否有该月记录 |
| 超支弹窗没有出现 | 支出需**大于**预算；同月只提醒一次，刷新页面后才会再次判断 |
| 搜索结果不对 | 检查是否处于搜索模式（`month` 会被忽略），尝试「清除搜索」后重试 |
| CSV 打开乱码 | 使用 Excel 直接打开；文件已带 BOM，请勿用文本编辑器另存为其他编码 |
| 导出按钮灰色 | 当前列表为空，先切换月份或调整筛选条件 |
| 删除分类失败 | 该分类下仍有账单，先删除或改分类后再删 |
| 数据在重新部署后消失 | 检查启动时 `LEDGER_DB_PATH` 是否指向原数据库文件 |
| npm build 内存不足 | 直接使用已构建好的 `frontend/dist`，无需在服务器重新构建 |
