## 1. 测试范围与方法

| 覆盖领域 | 说明 |
| --- | --- |
| 账单 CRUD | 新增、按月查询、全量编辑、删除、不存在资源、排序、必填/枚举/外键/类型一致性 |

| 非法月份 | `2026-13`、`2026-1`、`abc`（账单列表与月度报表两条路径） |

**方法**：对运行中的服务做 HTTP 黑盒测试，每条用例校验「HTTP 状态码 + 响应 `code` + 标准 `message` + 关键数据」。金额与占比按精确值比较（不允许浮点漂移）。

### 1.1 测试数据隔离（可复现性）

`spec.md` R-08 要求「所有自动化测试与验收用例必须显式传入 `month`」，本次严格执行。同时按月份隔离数据，避免用例之间互相污染：

| 月份 | 用途 |
| --- | --- |
| `2001-02` | **统计专用月**：只放 5 条已知种子数据（收入 300.00、支出 200.00） |
| `2001-06` | 噪音月：CRUD / 金额边界 / 备注边界产生的记录 |
| `2001-03` | 空数据月 |
| `2001-05` | 负结余月 |
| `2000-12`、`2001-01` | 跨年边界 |

脚本前置校验上述 7 个月份为空（用例 P-00），结束（含异常 `finally`）自动清理全部创建数据。

## 2. 问题清单（先列问题）

本次执行**未发现功能性缺陷**（无 P0/P1）。以下为需决策或改进的事项，均已定位、未擅自重构：

| 编号 | 严重度 | 类别 | 问题描述 | 建议 |
| --- | --- | --- | --- | --- |
| **Q-01** | 低 | 文档口径 | 金额缺省场景在文档中存在**两处可读解**：`spec.md §9 E-01` 写「金额非法（**空** / 非数字 / ≤ 0 / 超过 2 位小数）」→ 1002，而 `E-03` 写「必填缺失」→ 1001。实测行为是：**字段缺失 → 1001 参数不合法**，**显式 `null` → 1002 金额不合法**（用例 A-08a / A-08b）。两种行为都合理，但文档未明确区分边界 | 在 `spec.md §9` 或 §5.1 补一句：字段缺失归 E-03（1001），字段存在但为 `null`/空归 E-01（1002）。**仅需文档澄清，无需改代码** |
| **Q-02** | 低 | 测试环境 | 后端数据库路径 `DATABASE_FILE` 在 [config.py](file:///d:/Trae%20cn/personal-ledger/backend/app/core/config.py#L13-L14) 中为固定常量，**不支持环境变量覆盖**，因此测试数据会写入真实库 `backend/ledger.db`（本次已用月份隔离 + 自动清理规避风险） | 评审是否允许后续为 `DATABASE_FILE` 增加 env 覆盖（如 `LEDGER_DB`），以便使用独立测试库。属架构变更，**需你确认后另行处理** |
| **Q-03** | 低 | 测试资产 | 脚本首轮未做月份隔离，导致金额边界用例的大额记录（99,999,999.99 等）落入统计月，把 `total_expense` 污染为 100000297.32，造成 R-02/R-03/R-04 三条**假失败** | **已修复**：将 CRUD/边界数据迁至 `2001-06`，统计月仅保留种子数据，复测全绿。此为用例缺陷，非产品缺陷 |
| **Q-04** | 说明 | 范围限制 | 前端仅完成阶段 1（路由与整体布局，3 个页面为占位视图），因此「前后端联调」当前只能验证到 **API 可达 + CORS 端到端可用**；业务界面的联调（表单提交、列表渲染、饼图）需待前端阶段 2–5 完成后补充 | 前端阶段 2–5 完成后，将本报告的联调章节扩展为 UI 级用例 |
