| 字段 | 类型 | 约束 |

## 5. 用户操作流程

### 5.1 流程 A：记录一笔收支

1. 进入「账单管理」页（`/transactions`）。
2. 点击「新增」，弹窗默认带出当前月份上下文。
3. 选择收支类型（收入/支出）。
4. 填写金额、选择分类（下拉仅显示与所选类型一致且未被删除的分类）、选择日期（默认今天）。
5. 可选填写备注。
6. 点击「保存」，按钮进入禁用/加载状态，请求 `POST /api/transactions`。
7. 成功后弹窗关闭、列表刷新并提示成功；失败则就地展示字段级错误，弹窗保持打开。

异常分支：金额非法 → 金额字段下方提示；分类与类型不一致或分类不存在 → 提示并重置分类；网络异常 → 「网络异常，请重试」。

### 5.2 流程 B：修正或删除已有记录

1. 在账单列表定位记录（默认按 `date DESC, id DESC`）。
2. 编辑：点击「编辑」→ 弹窗回填类型/金额/分类/日期/备注 → 修改后保存（`PUT` 全量覆盖）。
3. 删除：点击「删除」→ 弹出「确认删除该记录？」→ 确认后调用 `DELETE`，列表刷新。

异常分支：记录不存在 → 「记录不存在」，关闭弹窗并刷新列表；切换类型时分类下拉重新加载并清空无效选择。

### 5.3 流程 C：维护分类

1. 进入「分类管理」页（`/categories`），查看支出组与收入组。
2. 新增：填写名称（1–20 字符）+ 选择类型 → 保存；重名时就地提示「该分类已存在」。
3. 删除：点击删除 → 二次确认 → 无引用则删除成功；被账单引用则提示「该分类下存在记录，无法删除」，确认框保持打开。

### 5.4 流程 D：月度复盘

1. 进入首页数据看板（`/`）。
2. 切换月份（默认当前月）。
3. 查看收入、支出、结余三项卡片；结余为负时显示负号与红色。
4. 查看支出分类饼图与明细，占比直接采用后端返回值。
5. 无数据时展示对应空状态，饼图隐藏。
